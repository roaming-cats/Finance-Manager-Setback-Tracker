# Finance-Manager-Setback-Tracker

A progressive financial web application designed to track money over time with a focus on achieving specific saving goals. Unlike standard trackers, it calculates how daily spending and unexpected "setbacks" impact the timeline for achieving those goals.

**Target Audience:**
Primary: Myself (to replace manual calculator/paper tracking).
Secondary: Students or individuals with fixed allowances/incomes who need to balance expenses (transport, food) against material goals (GPUs, clothes, etc.).

* **Frontend:** TypeScript + React (Vite) + Tailwind CSS
* **Backend:** TypeScript + Express/Node
* **Database:** PostgreSQL
* **Hosting/Deployment:** Vercel
